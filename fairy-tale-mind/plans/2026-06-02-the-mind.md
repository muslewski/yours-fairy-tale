# The Mind Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Stand up `fairy-tale-mind/` — an Obsidian-vault repository knowledge base (the Map of present-tense zone cards + the Ledger of past-tense specs/plans/decisions/tech-debt), a Node generator that verifies anchors/freshness and gates the build, a SessionStart status hook, and `.claude/` projections that point into it.

**Architecture:** A committed Markdown vault is the single source of truth. A Node ESM generator (`scripts/mind/generate.mjs`, using the already-installed `gray-matter` + `git`) validates every zone's globs/anchors against the real code, computes freshness from git history, writes `map/index.md`, and exits non-zero on broken anchors — wired into `prebuild` so `npm run build` fails loudly. A pure-file-I/O `status.mjs` prints an orientation line on session start. `.claude/` (CLAUDE.md rule, a navigating skill, a `/map-sync` command) only points into the vault.

**Tech Stack:** Node ESM scripts · `gray-matter` (already a dep) · `git` CLI · Next.js 16 build as the gate. No new dependencies.

> **Spec:** `docs/superpowers/specs/2026-06-02-the-mind-design.md` (committed). It holds the full property schema, the anchor model, and the **canonical 11-zone table with exact globs/anchors** — the implementer should read that table for the per-zone values rather than re-deriving them. This plan gives the exact file formats + one fully-worked example of each note type.

> **Testing note.** No unit-test harness in this repo by design. The verification gate for this feature *is* the generator: `node scripts/mind/generate.mjs` must exit 0 with every zone green, and `npm run build` (which now runs it via `prebuild`) must pass. Each task ends with a generator run + a commit.

```markdown
# fairy-tale-mind — the Mind

Single source of truth for understanding this repo. An Obsidian vault: YAML
frontmatter = properties, `[[wikilinks]]` connect notes. Everything in `.claude/`
is a projection or pointer into here — never a copy.

## Map vs Ledger
- **Map** (`map/`) — PRESENT tense: what IS. Mutable, tracks the code.
- **Ledger** (`specs/ plans/ ideas/ tech-debt/`) — PAST tense: why/how we decided
  & built it. Read-only once consumed — **supersede, don't edit; tombstone, don't delete.**

Lineage joins them: `prompt → idea → spec → plan → [implementation] → zone card / decision`.
Read the cheapest note that answers the question: `map/index.md` → `map/zones/<slug>.md`
→ the code → `map/decisions/`.

## Universal frontmatter (every note)
\`\`\`yaml
type: zone        # zone | entity | flow | decision | spec | plan | idea | debt
summary: "1–3 sentence human glance."
tags: []
status: active
created: YYYY-MM-DD
updated: YYYY-MM-DD
related: []       # lateral [[wikilinks]]
sources: []       # lineage [[wikilinks]]
\`\`\`

## Per-type extras
- **zone** → `owns: { routes, anchors, globs }`, `depends`, `invariants: [{rule, enforcedBy}]`, `verifiedAt`
- **entity** → `anchor`, `intent`
- **flow** → `steps`, `verify`, `e2e`
- **decision** → `decided`, `supersededBy`
- **spec** → `origin`
- **plan** → `implements`, `produced`
- **idea** → `maturity`
- **debt** → `severity`, `effort`

## Lifecycle (status)
- spec: `draft → planned → superseded`
- plan: `draft → executing → done → abandoned`
- debt: `open → done → wontfix`
- idea: `active → promoted → archived`
- zone/flow/entity/decision: `active → unmounted` (tombstone)

## Anchors (verified by scripts/mind/generate.mjs)
- `globs` — primary; each must match ≥1 tracked file.
- `id:<name>` — greps `id="<name>"` in app/+components.
- `route:<path>` — resolves to an `app/**/page.tsx|route.ts`.

Do not hand-edit `map/index.md` — it is generated. Run `npm run mind` (or `/map-sync`).
```

- [ ] **Step 1: Write `scripts/mind/generate.mjs`** (exact content)

```js
#!/usr/bin/env node
// Validates the Map against the real code, writes fairy-tale-mind/map/index.md,
// and exits non-zero on any hard error. Run via `npm run mind` / `prebuild`.
import { readFileSync, readdirSync, writeFileSync, existsSync } from "node:fs";
import { execFileSync } from "node:child_process";
import { join, dirname } from "node:path";
import { fileURLToPath } from "node:url";
import matter from "gray-matter";

const ROOT = join(dirname(fileURLToPath(import.meta.url)), "..", "..");
const VAULT = join(ROOT, "fairy-tale-mind");
const ZONES_DIR = join(VAULT, "map", "zones");
const FLOWS_DIR = join(VAULT, "map", "flows");
const DEBT_DIR = join(VAULT, "tech-debt");
const INDEX = join(VAULT, "map", "index.md");

const errors = [];
const gaps = [];

function gitOut(args) {
  try {
    return execFileSync("git", args, { cwd: ROOT, encoding: "utf8" }).trim();
  } catch {
    return "";
  }
}

function tracked(glob) {
  const out = gitOut(["ls-files", "--", glob]);
  return out ? out.split("\n").filter(Boolean) : [];
}

function grepFiles(needle, dirs) {
  // git grep exits 1 when nothing matches → gitOut returns "" → []
  const out = gitOut(["grep", "-l", "--fixed-strings", needle, "--", ...dirs]);
  return out ? out.split("\n").filter(Boolean) : [];
}

function routeExists(route) {
  const seg = route === "/" ? "" : route.replace(/^\//, "");
  const base = join(ROOT, "app", seg);
  return ["page.tsx", "page.jsx", "route.ts", "route.tsx"].some((f) =>
    existsSync(join(base, f)),
  );
}

function anchorResolves(anchor) {
  const i = anchor.indexOf(":");
  const kind = anchor.slice(0, i);
  const val = anchor.slice(i + 1);
  if (kind === "id") return grepFiles(`id="${val}"`, ["app", "components"]).length > 0;
  if (kind === "route") return routeExists(val);
  return false; // unknown anchor kind
}

function isStale(verifiedAt, globs) {
  if (!verifiedAt) return true;
  try {
    const out = execFileSync(
      "git",
      ["rev-list", `${verifiedAt}..HEAD`, "--", ...globs],
      { cwd: ROOT, encoding: "utf8" },
    ).trim();
    return out.length > 0;
  } catch {
    return true; // unknown/invalid SHA → treat as stale
  }
}

function readNotes(dir, type) {
  if (!existsSync(dir)) return [];
  return readdirSync(dir)
    .filter((f) => f.endsWith(".md"))
    .map((f) => {
      const { data } = matter(readFileSync(join(dir, f), "utf8"));
      return { slug: f.replace(/\.md$/, ""), data };
    })
    .filter((n) => !type || n.data.type === type);
}

const zones = readNotes(ZONES_DIR, "zone");
const flows = readNotes(FLOWS_DIR, "flow");
const debt = readNotes(DEBT_DIR, "debt");

const rows = [];
const attic = [];

for (const z of zones) {
  const d = z.data;
  const owns = d.owns || {};
  const globs = owns.globs || [];
  const anchors = owns.anchors || [];

  if (d.status === "unmounted") {
    attic.push({ slug: z.slug, summary: d.summary || "" });
    continue;
  }

  for (const g of globs) {
    if (tracked(g).length === 0) errors.push(`zone "${z.slug}": glob "${g}" matches no tracked file`);
  }
  for (const a of anchors) {
    if (!anchorResolves(a)) errors.push(`zone "${z.slug}": anchor "${a}" does not resolve in code`);
  }
  for (const inv of d.invariants || []) {
    if (!inv.enforcedBy || inv.enforcedBy.length === 0)
      gaps.push(`zone "${z.slug}": invariant "${inv.rule}" has no enforcedBy`);
  }

  const stale = isStale(d.verifiedAt, globs);
  rows.push({
    slug: z.slug,
    status: d.status || "active",
    fresh: stale ? "⚠ stale" : "✓ fresh",
    summary: (d.summary || "").replace(/\|/g, "\\|"),
  });
}

for (const f of flows) {
  for (const step of f.data.steps || []) {
    if (step.startsWith("id:") || step.startsWith("route:")) {
      if (!anchorResolves(step)) errors.push(`flow "${f.slug}": step "${step}" does not resolve`);
    }
  }
}

rows.sort((a, b) => a.slug.localeCompare(b.slug));
const staleCount = rows.filter((r) => r.fresh.startsWith("⚠")).length;
const openDebt = debt.filter((n) => (n.data.status || "open") === "open").length;

let md = "";
md += "<!-- GENERATED by scripts/mind/generate.mjs — do not hand-edit. Run `npm run mind` or /map-sync. -->\n";
md += `<!-- mind:counts zones=${rows.length} stale=${staleCount} debt=${openDebt} -->\n`;
md += "# Map Index\n\n";
md += "| Zone | Status | Freshness | Summary |\n|---|---|---|---|\n";
for (const r of rows) md += `| [[${r.slug}]] | ${r.status} | ${r.fresh} | ${r.summary} |\n`;
md += "\n## ⚠ Verification gaps\n\n";
md += gaps.length ? gaps.map((g) => `- ${g}`).join("\n") + "\n" : "_None._\n";
md += "\n## Attic\n\n";
md += attic.length
  ? attic.map((a) => `- [[${a.slug}]] — ${a.summary}`).join("\n") + "\n"
  : "_Empty._\n";

writeFileSync(INDEX, md);
console.log(`🧠 Mind: ${rows.length} zones, ${staleCount} stale, ${openDebt} open debt, ${gaps.length} gaps.`);

if (errors.length) {
  console.error("\n✖ Mind verification FAILED:\n" + errors.map((e) => "  - " + e).join("\n"));
  process.exit(1);
}
```

- [ ] **Step 2: Write `scripts/mind/status.mjs`** (pure file I/O)

```js
#!/usr/bin/env node
// SessionStart orientation line. Pure file I/O — no exec.
import { readFileSync, existsSync } from "node:fs";
import { join, dirname } from "node:path";
import { fileURLToPath } from "node:url";

const ROOT = join(dirname(fileURLToPath(import.meta.url)), "..", "..");
const INDEX = join(ROOT, "fairy-tale-mind", "map", "index.md");

if (!existsSync(INDEX)) {
  console.log("🧠 Mind: index not built yet — run `npm run mind` (or /map-sync).");
  process.exit(0);
}

const m = readFileSync(INDEX, "utf8").match(/mind:counts zones=(\d+) stale=(\d+) debt=(\d+)/);
if (m) {
  const [, zones, stale, debt] = m;
  const staleNote = Number(stale) ? ` (${stale} ⚠ stale)` : "";
  console.log(
    `🧠 Mind: ${zones} zones${staleNote} · ${debt} open tech-debt — orient via fairy-tale-mind/map/index.md before coding.`,
  );
} else {
  console.log("🧠 Mind: orient via fairy-tale-mind/map/index.md before coding.");
}
```
